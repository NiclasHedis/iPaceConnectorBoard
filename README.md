# Jaguar-iPace-Inverter connector board
<img width="2279" height="1048" alt="image" src="https://github.com/user-attachments/assets/eafca42c-a48b-4701-811d-a4cac0dfc7d2" />
This PCB is used to replace the OEM board for the 28pin connector interfacing the vehicle harness when using the Openinverter iPace main board. (https://github.com/damienmaguire/Jaguar-iPace-Inverter)

## Instructions:
Original J1 (28pin TE connector mounted in the housing) is used, FPC-connector is the same so the original flex cable is reused, same with the water temp sensor.  
Just mount the board and solder the 28pin connector.

The OEM pcb is using a press fit connector, so use a flat screwdriver to remove it by bending from different directions.

### Components:
* R1, R2 - 0805 10kOhm.
* J1 - OEM in housing
* J2 - Hirose ZE05H-2P-2V - https://mou.sr/3UHuiN9
* J3 - Kyocera 046810650020846+T - https://mou.sr/4iiVvzu
